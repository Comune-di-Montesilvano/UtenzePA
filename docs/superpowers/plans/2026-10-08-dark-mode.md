# Dark mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tema scuro automatico (segue il sistema) con selettore Chiaro / Scuro / Sistema nella sidebar, identità monocromatica, rilascio v1.17.0.

**Architecture:** Un solo tema Material M3 con `theme-type: color-scheme`; tutti i colori dell'app sono token CSS `light-dark(chiaro, scuro)`; il tema effettivo dipende solo dalla proprietà `color-scheme` di `<html>` (default `light dark` = sistema, classi `theme-light`/`theme-dark` per forzarlo). `ThemeService` salva la preferenza in `localStorage`, uno script inline in `index.html` la applica prima del bootstrap.

**Tech Stack:** Angular 22 standalone, Angular Material 22 (M3, `mat.theme`), SCSS, CSS `light-dark()`, Leaflet (solo controlli), Playwright MCP per la verifica.

**Spec:** `docs/superpowers/specs/2026-10-08-dark-mode-design.md`

## Global Constraints

- Scuro: sfondo `#121212`, superficie `#1c1c1e`, superficie alta `#26262a`, bordo `#34343a`, testo `#e7e7ea`, muted `#9a9aa3`.
- Primario: `light-dark(#030213, #ececf0)`, on-primary `light-dark(#ffffff, #0b0b12)`.
- Chiave `localStorage`: `utenzepa-theme`, valori `light` | `dark` | `system` (assente o non valido = `system`); ogni accesso in `try/catch`.
- Classi su `<html>`: `theme-light`, `theme-dark`; nessuna classe = sistema.
- Tessere della mappa invariate; colori "dato" (tipo utenza `hard-type.enum.ts`, pin/cluster mappa, serie dei grafici) invariati.
- Testo con contrasto WCAG AA (4,5:1; 3:1 per testo grande) in entrambi i temi.
- Nessuna modifica backend, nessuna migration. Versione `v1.17.0`.
- Frontend: nessun runner di test eseguibile (Karma senza browser, CI fa solo `build`). Verifica = `pnpm run build` nel container `frontend` + Playwright MCP dall'host (`http://localhost:4300`).
- Comandi Docker uno alla volta. Sorgenti con CRLF: preservare le terminazioni (Edit tool le preserva; niente riscritture con LF).
- Mai `git add .`/`-A`: elencare i file.
- Attributi di presentazione SVG (`fill="…"`, `stroke="…"`) **non** accettano `var()`: usare `style="fill: var(--x)"` o `[style.fill]`.
- Angular `[style.background]="'var(--x)'"` funziona (nessuna sanitizzazione degli stili da Angular 10).

- [ ] **Step 1: ThemeService**

Create `frontend/src/app/core/services/theme.service.ts`:

```ts
import {Injectable, signal} from '@angular/core';

export type ThemePreference = 'light' | 'dark' | 'system';

// Stessa chiave letta dallo script inline di index.html (applica il tema
// prima del bootstrap, niente lampo bianco): tenerle allineate.
export const THEME_STORAGE_KEY = 'utenzepa-theme';

const CLASSES: Record<Exclude<ThemePreference, 'system'>, string> = {
  light: 'theme-light',
  dark: 'theme-dark',
};

function isPreference(value: unknown): value is ThemePreference {
  return value === 'light' || value === 'dark' || value === 'system';
}

/**
 * Preferenza di tema del browser (non dell'utente: niente backend).
 * "system" = nessuna classe su <html>, decide color-scheme: light dark.
 */
@Injectable({providedIn: 'root'})
export class ThemeService {
  private readonly pref = signal<ThemePreference>(ThemeService.read());
  readonly preference = this.pref.asReadonly();

  constructor() {
    this.apply(this.pref());
  }

  set(pref: ThemePreference): void {
    this.pref.set(pref);
    try {
      localStorage.setItem(THEME_STORAGE_KEY, pref);
    } catch {
      // storage bloccato: la scelta vale fino alla ricarica
    }
    this.apply(pref);
  }

  private apply(pref: ThemePreference): void {
    const root = document.documentElement;
    root.classList.remove(CLASSES.light, CLASSES.dark);
    if (pref !== 'system') {
      root.classList.add(CLASSES[pref]);
    }
  }

  private static read(): ThemePreference {
    try {
      const value = localStorage.getItem(THEME_STORAGE_KEY);
      return isPreference(value) ? value : 'system';
    } catch {
      return 'system';
    }
  }
}
```

```js
() => {
  const lum = (hex) => {
    const c = hex.match(/\d+/g).slice(0, 3).map(v => { v /= 255; return v <= 0.03928 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4; });
    return 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2];
  };
  const probe = (fg, bg) => {
    const el = document.createElement('div');
    el.style.color = `var(${fg})`; el.style.background = `var(${bg})`;
    document.body.appendChild(el);
    const s = getComputedStyle(el); const a = lum(s.color), b = lum(s.backgroundColor);
    el.remove();
    return ((Math.max(a, b) + 0.05) / (Math.min(a, b) + 0.05)).toFixed(2);
  };
  const pairs = [['--app-muted','--app-surface'],['--app-text','--app-bg'],['--app-link','--app-surface'],['--app-error','--app-surface'],
    ['--tone-ok-fg','--tone-ok-bg'],['--tone-warn-fg','--tone-warn-bg'],['--tone-danger-fg','--tone-danger-bg'],['--tone-off-fg','--tone-off-bg'],
    ['--tone-info-fg','--tone-info-bg'],['--tone-disputed-fg','--tone-disputed-bg'],['--mat-sys-on-primary','--mat-sys-primary']];
  return Object.fromEntries(pairs.map(([f, b]) => [`${f} / ${b}`, probe(f, b)]));
}
```
